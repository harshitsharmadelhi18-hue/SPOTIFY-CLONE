# 🎵 Spotify Clone

A **Spotify-inspired music streaming web interface** built using **HTML and CSS**.
This project recreates the look and feel of the Spotify Web Player with a responsive layout, navigation sidebar, music cards, featured charts, and a bottom music player.

> ⚠️ This project is created for **educational and frontend development purposes** and is not affiliated with Spotify.

## ✨ Features

* 🎧 Spotify-inspired dark user interface
* 🏠 Home and Search navigation
* 📚 Your Library section
* 🎵 Recently Played section
* 🔥 Trending music section
* 📊 Featured Charts
* ⏯️ Music player controls UI
* 🎚️ Playback progress bar
* ⬅️ Back and forward navigation buttons
* 📱 Responsive layout for smaller screens
* 🖼️ Music album artwork and icons
* ✨ Hover effects for interactive UI elements

## The main interface is structured around a sidebar, main content area, and fixed music-player section.

## 🎨 UI Sections

### Sidebar

The sidebar contains:

* Home
* Search
* Your Library
* Create Playlist
* Browse Podcasts

### Main Content

The main section contains:

* Recently Played
* Trending Now
* Featured Charts

Music cards display album artwork, song titles, artists, and descriptions.

### Music Player

A fixed bottom player contains:

* Previous
* Play/Pause
* Next
* Additional player controls
* Current playback time
* Progress bar
* Total duration

The player is fixed to the bottom of the viewport using CSS.

## 💻 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/spotify-clone.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd spotify-clone
```

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

No additional installation or dependencies are required.
